ダイヤグラム

在線共有モードの列車だけを表示します（特発のみ共有の列車は出ません）。実績（実線）と、標準運転時分による見込み（点線）。◆は進路を扱う駅を通過する（停車駅は着く）予想時刻で、見込みの線の上に置きます。 進路は「2つ手前の駅に着いた」ときに開通します（フリーモードでは時刻に依らない）。開通の時刻は◆にマウスを乗せると出ます。 行き止まりの番線（駒野の下り1・2番線、日野森の上り1番線）を選ぶと、列車はその駅で打ち切りになり、線もそこで切れます。 ◆の右の数字は番線（通＝通過、橙＝集中扱いの指定・駅扱い、紫＝待避）。◆をクリックすると番線を変えられます。開通済みでも、列車がまだ進路に入っていなければ取り直します。 ◆の窓では、駅扱い（「本線→1番線」など。連動に問題がなければ抑止・待ちを無視して開通）、場内抑止・出発抑止、その駅の出発順序（上下とも）と、単線区間の走行順を指定できます。 ◆見込み ◆指定 ◆抑止中 ◆開通済み

出発順序・単線区間の走行順

駅を選ぶと、その駅をこれから通る列車（上下とも）を、出発順序に並べ替えて指定できます。進路が競合する列車どうしは、先の列車が駅を抜けるまで後の列車を出発させません（競合しない番線の場内・出発は開けます）。 番線もここで変えられます。単線区間を選ぶと、その区間を通る順番（例: 1051 → 903A → 1040）を指定できます。

進路・集中扱い

在線共有モードの列車の、この先の駅ごとの番線と状態です。番線はダイヤ（列車一覧）を基本にし、ダイヤにない列車は種別ごとの所定です。番線を選ぶと集中扱いの指定になり、列車扱い（ユーザーの選択・ダイヤ・所定・待避）より優先されます。 「場内抑止」「出発抑止」はその駅のその信号を出させません。すでに開通している進路は、列車がまだ接近していなければ取り消します（運転士の目の前で信号が急に変わる範囲に来ていれば、取り消さずに残します）。 「自動開通」は抑止を外し、手前の駅に着いていなくても、安全を確認でき次第開通させます。 「駅扱い」は選んだ進路を、連動に問題がなければ（進路に他の列車がいない・他の列車の進路と重ならない）抑止や待ちを無視して開通させます。

手動進路（管理者）

進路名を直接選んで、その列車のゲームに開通・取消させます。連動の確認も、列車が接近しているかの確認もしません（運営中に詰んだとき用の強制の操作）。取り消した駅は、自動で開き直さないように抑止になります。

駅の扱い

集中扱いの駅は、列車ごとに「自動開通」を押すまで自動では開通させません。

待避

後ろの特急に「余裕」より近く追いつかれる見込みなら待避させます。特急が見込みより「許容の遅れ」以上遅れたら、待たずに発車させます。
